## 📖 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades técnicas e projetos construídos durante meus estudos.

Atualmente, sou estudante de **Análise e Desenvolvimento de Sistemas pela FATEC** e estou aprofundando meus conhecimentos em desenvolvimento web, lógica de programação e construção de interfaces responsivas.

O objetivo deste portfólio é reunir meus principais projetos e demonstrar minha evolução como desenvolvedor, com foco em conquistar minha primeira oportunidade na área de tecnologia.
